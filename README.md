# thoughtful releases

Signed and notarized builds of thoughtful, a private relationship manager for macOS.

- **Install:** download the latest `.dmg` from Releases, open it and drag thoughtful into Applications.
- **Updates:** thoughtful checks this repository once a day and asks before installing anything new.
- **Verification:** every update is signed with the project's update key and with its Developer ID; the app refuses anything that doesn't match both.

This repository holds release files only.
